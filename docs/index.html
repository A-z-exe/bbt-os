About

I build tools for authorized security testing. BBT OS is an installable overlay that turns a stock Kali Linux system into a focused bug bounty workstation, with a searchable launcher, matched tool chains and a hard scope gate: nothing runs without an explicit authorization flag and an in-scope target file.

All testing must stay inside a published bug bounty scope or a system you own. The projects never include exploits against third parties.
